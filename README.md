A simple app that was asked for so that they could track/rate/organize the movies they were watching.

Steps needed
Set up a Firebase project with 
1. Firebase Authentication turned on for username and password
2. Firestore turned on

Download the resulting google-services.json and put it in the /app folder

Next goto TMDB [www.themoviedb.org] and register an api key and put in the local.properties a line that is:
tmdb_api_key=your key here
